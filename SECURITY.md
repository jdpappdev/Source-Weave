# Security Policy

Source-Weave currently contains agent instructions and Markdown templates. It does not include a server, executable research tool, or credential-handling component.

## Reporting a concern

Do not publish sensitive details in a public issue. Use GitHub's **Report a vulnerability** option on the repository's Security tab when available. If private vulnerability reporting is unavailable, use the contact options on the [jdpappdev GitHub profile](https://github.com/jdpappdev) to arrange a private channel before sharing sensitive details.

Include the affected file or revision, the behavior observed, steps to reproduce, and the potential impact. Do not include real credentials, private data, or destructive proof-of-concept material.

There is no formal support or response-time commitment. Reports will be assessed as maintainers are available.
